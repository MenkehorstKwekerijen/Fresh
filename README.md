# Fresh

Fresh begint met een compacte, spec driven ontwikkelwerkwijze. Dit repository bevat
de procesbasis; productregels en de applicatiestack zijn nog niet vastgesteld.

- **Bijdragen:** lees [de werkwijze](docs/workflow.md).
- **Als agent:** begin bij [AGENTS.md](AGENTS.md).
- **Document maken:** gebruik de [documentafspraken](docs/documentation.md).
- **Controles uitvoeren:** volg de [controlehandleiding](docs/guides/checks.md).
- **Herkomst van de projectskills:** zie [het skillprofiel](docs/skills.md).

Werk, besluiten en voortgang staan in GitHub Issues en Pull Requests. Er is geen
apart Project-bord of handmatig voortgangsdocument. Een gesloten issue bewijst
alleen de scope en afsluitreden die bij dat issue zijn vastgelegd.
